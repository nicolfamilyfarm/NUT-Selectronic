# Security Policy

## Supported Versions

This project does not currently publish versioned releases. Security fixes are
applied to the `main` branch and, when appropriate, included in the next
container image build.

| Version | Supported |
| ------- | --------- |
| `main`  | :white_check_mark: |
| Older commits and local builds | :x: |

Use the latest commit or image when deploying this project. Podman/Docker,
Network UPS Tools, the Selectronic inverter firmware, and the host operating
system should also be kept up to date.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public GitHub issue or pull
request.

Use GitHub's private vulnerability reporting or Security Advisory workflow for
this repository. Include:

- a clear description of the vulnerability and its potential impact;
- the affected commit, image, or configuration;
- reproduction steps or a minimal proof of concept;
- any required network placement, credentials, or device state; and
- a suggested mitigation, if available.

You should receive an acknowledgement within seven days. We will investigate
the report, keep the reporter informed as the assessment progresses, and
coordinate disclosure after a fix or mitigation is available. Reports that do
not affect this project or cannot be reproduced may be closed with an
explanation.

## Deployment Security

- Set a strong, unique `NUT_PASSWORD`; do not use the documented default.
- Publish the NUT port only to trusted networks and restrict access with the
  host firewall where possible.
- Do not include NUT passwords, device identifiers, serial numbers, local IP
  addresses, or inverter responses in public reports or logs.
- The Selectronic local API is accessed over HTTP. Keep the inverter and the
  container on a trusted network, and do not expose the inverter API or NUT
  service directly to the public Internet.
- Treat telemetry exposed through NUT as sensitive operational data.

## Scope

Reports are in scope when they affect the container image, entrypoint,
poller, NUT configuration generated by this project, or documented deployment
instructions. Vulnerabilities solely in third-party dependencies, the host,
container runtime, web monitor, or Selectronic firmware should also be
reported to the relevant upstream project, while a project-specific impact is
still useful to report here.
